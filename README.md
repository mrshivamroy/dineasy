# Dineasy

Dineasy is a full-stack restaurant website built with the MERN stack (MongoDB, Express, React, Node.js). It allows users to make reservations through a responsive React frontend and a RESTful Node backend. The project features a MongoDB database for data storage of reservations.

## Setup
1. Install dependencies in `/backend` and `/frontend`.
2. Configure `.env` with MongoDB URI .
3. Run backend (`npm run dev`) and frontend (`npm run dev`).

Visit `http://localhost:3000` to explore Dineasy.
